# 方块大战开发步骤

设计依据：[首版开发设计](superpowers/specs/2026-10-06-block-battle-design.md)。用户已于 2026-10-06 确认设计。

本文只安排实施顺序，不新增玩法范围，不代表游戏功能已实现。

## 1. 工程基础

- 核实 TypeScript、Phaser、Vite 的官方稳定版本，锁定依赖。
- 建立开发、类型检查、测试和生产构建命令。
- 根目录 VERSION 保持唯一产品版本来源，构建时读取并注入。
- 建立角色、技能、敌人和阶段的集中配置及稳定 ID。
- 设置几何颜色、尺寸、轮廓与界面样式常量。

验收：开发服务与生产构建均可运行，显示几何首页，无控制台未处理错误。

## 2. 核心可玩原型

- 实现世界坐标、镜头、地图边界与基础障碍。
- 实现键盘和多点触控移动，处理输入取消、失焦与后台暂停。
- 加入圆形角色、轨道攻击、追击怪、生命与伤害保护。
- 加入经验掉落、吸取、等级和暂停三选一。
- 完成死亡、结算、重新开始。

验收：电脑与手机可连续游玩；斜向速度一致；升级和暂停冻结战斗；重开清除上一局对象和监听器。

## 3. 角色与战斗

- 加入正方形、三角形和各自专属攻击。
- 实现普通技能、大招、冷却与能量反馈。
- 加入六个通用技能及四槽限制。
- 完成五类敌人、预警、简单绕障与阶段刷怪。
- 引入空间网格和对象池，限制装饰对象数量。

验收：三角色手感有明显差异；移动与技能可同时操作；冲刺不越界；同次攻击命中次数符合规则。

## 4. 构筑与完整一局

- 实现技能等级、行为强化、三种元素与三种融合。
- 实现候选过滤、两次重抽、多级待选项和事件免费奖励。
- 加入两种精英、两类事件、六边核心首领。
- 完成战斗阶段、胜负优先级与十二分钟时限。

验收：所有构筑选项合法；元素不能递归触发；可完成完整胜利与失败流程；地图事件可跳过。

## 5. 完整界面与本地保存

- 完成几何首页、角色选择、升级卡片、设置和结算。
- 实现解锁条件、最高成绩、累计统计和存档结构校验。
- 加入音乐与音效、独立音量、减少动态效果选项。
- 实现横竖屏、安全区和不同尺寸布局。

验收：正常存档重开后保留；损坏或禁用存储不阻止游玩；技能和危险范围在小屏上清晰可辨。

## 6. 发布验证

- 自动化验证经验跨级、候选池、技能槽、元素触发、命中和胜负时序。
- 检查生产构建与静态 HTTP 服务访问。
- 在 Windows Chrome/Edge、Android Chrome、iOS Safari 验证完整流程。
- 记录测试设备、浏览器版本、画质、后期场景与帧耗时。
- 根据真机结果调整光晕、粒子、尾迹、伤害数字和渲染像素比。

验收：通过设计文档的验收清单；未测试的设备明确标注；性能未达标时不宣称完成性能验收。

## 7. 每个独立任务的交付规则

实现 → 检查 diff → 完成相关验证 → 按 SemVer 更新 VERSION → 更新 CHANGELOG → 创建单一目的的 Conventional Commit。
