# 浏览器验收记录

日期：2026-10-06。环境：Windows、Chrome，本地开发服务器。测试存档使用 `http://127.0.0.1:5173/`，与用户试玩的 `http://localhost:5173/` 独立。

## 已验证

- 首页默认圆形，另外两种形态显示对应解锁条件；首次开始显示操作说明，异步加载后出现真实 Phaser 战场。
- 圆形普通技能按钮触发轨道扩张并进入冷却；大招能量不足时禁用。Esc 暂停与恢复后，生命、技能与时间继续更新，没有同一次按键立即重复暂停。
- 360 × 800 竖屏：DOM 实际视口为 360 × 800，页面宽度 360，无横向溢出。摇杆 112 × 112，普通技能 67 × 86，大招 75 × 98，互不重叠。角色位于战斗视野中央。
- 800 × 360 横屏：真实画布、HUD、摇杆与技能按钮可见；极端比例保留左右视野边界。
- 设置中开启自动普通技能、选择低画质；重载后对应控件仍保持选择。
- 圆形死亡显示存活时间、伤害统计、构筑、重开与首页操作；完成一局解锁正方形，返回首页并重载后仍可选择。
- 正方形战斗可获得经验并升级；三选一面板冻结战斗，Esc 无法跳过，重抽从 2 / 2 减至 1 / 2，选中地面雷区后出现在技能槽并恢复战斗。
- 竖屏升级面板、设置面板具备独立 `overflow: auto` 滚动容器；关于触摸滚动冲突的初步候选经代码复核撤回，未因此修改 CSS。
- 返回首页先显示放弃局确认；取消回到暂停面板，确认返回首页；放弃的成绩不覆盖已完成成绩。
- 上述浏览器流程的控制台没有捕获到 error / warn。
- 修复后的手机首页“打开操作说明”图标按钮具有中文可访问名称，点击可打开说明，关闭后回到首页。
- 生产构建通过 `vite preview` 的 HTTP 静态服务打开，首页与异步战场分块正常加载，可进入真实画布并暂停。生产页面日志捕获到一条 Chrome 扩展自身的 fetch 错误，来源为 `chrome-extension://.../content_main.js`，未捕获游戏脚本错误。

## 自动验证与脚本试玩

最终暂停与音频修复后，类型检查、生产构建及 69 项自动测试通过。详细结果见任务报告和实施进度。

额外使用正常生命、合法升级的走位脚本演练完整核心：正方形约 570 秒、三角形约 563 秒击败首领。圆形在同一脚本策略下失败；关闭自动普通技能后也失败。脚本不是真人操作，其失败不足以判定圆形数值或自动技能存在缺陷，未据此擅自调整平衡。此演练只验证核心模拟，不等同于浏览器完整通关。
