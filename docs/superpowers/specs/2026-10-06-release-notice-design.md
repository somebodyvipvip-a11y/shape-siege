# 首页版本公告

用户要求首页增加更新公告，仅首次打开提醒。按产品版本实现：每个版本首次显示一次，刷新、返回首页和重新打开相同版本不自动弹出，下个版本重新提醒。

- 使用现有弹窗容器、遮罩、首页 inert、焦点限制与 Esc 关闭机制，适配手机滚动。
- 公告直接读取 CHANGELOG 的前两个版本及顶层项目，转义文本，不执行 Markdown HTML；运行版本来自唯一来源 VERSION。
- SaveData 增加 seenReleaseVersion 字符串，沿用 schema 1 的缺失字段补齐逻辑，保留已有设置、角色与成绩。公告显示时即记已读，避免未关闭就刷新反复弹出。
- 存储失败时在内存中保留已读并使用既有保存失败提示；清除存储或换浏览器会重新提醒。
- 首页“更新公告”入口支持主动回看，不改变自动提醒规则，不与新手说明叠加。

验证同版本刷新、下版本重新提醒、旧存档补齐、保存失败、进度保留、公告提取与转义、Esc 关闭、桌面与手机布局，以及类型检查和构建。不增加第三方依赖。本轮仅本地提交，发布按最新用户指令执行。
