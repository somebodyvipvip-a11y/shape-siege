# 任务 2：几何界面与完整浏览器游戏

已批准产品：单人浏览器几何肉鸽生存游戏；逻辑由 src/game 的 GameWorld 实现，本任务接入 Phaser 绘制、界面、手机输入、保存和声音。

## 需求来源

读取 docs/superpowers/specs/2026-10-06-block-battle-design.md 第 3、4、6.3、9、10、12 节；读取任务 1 报告的实际接口，不重新实现战斗规则。

## 文件组织

src/main.ts 只启动；src/app.ts 管理页面和对局生命周期；src/render/scene.ts、geometry.ts 绘制；src/input.ts 统一键盘和多点触控；src/ui/ 下 menu.ts、hud.ts、overlays.ts、styles.css；src/storage.ts 本地保存；src/audio.ts 合成音效和背景音乐。允许按职责增补小文件，不写单个巨型文件。

## 界面与风格

- 精致、清晰的深色几何风格，使用设计中的颜色。首页有品牌标题“方块大战”、简洁玩法说明、三个几何角色选择卡、较大开始按钮、操作/设置入口、版本和本地最好成绩。
- 首页视觉重点为可动几何主角与轨道装饰，可使用 Phaser 背景或 CSS/SVG 原创几何视觉。不能只是黑色页面上几个默认按钮。
- 默认圆形已解锁，正方形在完成任意局后解锁，三角形在首次击杀阶段精英后解锁；锁定卡说明条件。结算及时显示新解锁。
- 主角形状、怪物轮廓、技能图形、事件标记、掉落和障碍均遵从设计。提供角色方向标记，圆形也能看出最后移动方向。渲染明显区分敌方预警、友方技能、碰撞障碍。
- 战斗 HUD：生命、护盾、等级/经验、计时、击杀、技能槽、暂停、普通技能冷却、大招能量；首领阶段显示血条；事件方向/进度。低频更新 DOM，画布每帧绘制。
- 手机左右触控区清楚但不遮挡主角；PC 可保留按钮并附键位。三选一大卡片，支持重抽次数和具体属性增量；事件奖励与连续升级正确展示。
- 暂停、设置、操作说明、胜负结算完整。结算展示各技能伤害、角色解锁、重开/返回。禁用和就绪状态清晰，所有图标按钮有中文 aria-label。
- 通用界面图标使用 lucide 1.52.0（已通过官方 npm 查询）；角色与技能使用原创几何 SVG/画布。不用 Emoji。

## 输入、适配与生命周期

- WASD/方向键移动、空格普通技能、Q大招、Esc 暂停；斜向归一化由 engine 完成。忽略文字输入焦点的快捷键。
- 手机摇杆跟踪独立 pointerId，左右多点触控不冲突；pointer capture、pointercancel、window blur 清理状态。技能为单次事件。
- 游戏失焦/后台立即暂停，返回只能手动继续。升级暂停不计时；暂停不能绕过待选升级。
- 窗口/手机旋转重新布局、清理旧输入，保留对局；安全区和至少 56px 按钮；宽度 360px 不溢出。战斗禁止滚动和双击缩放，其余菜单允许必要滚动。
- Phaser 画布处理 resize，限制像素比；等面积视野并向 GameWorld.setViewport 传实际世界可视范围。极端宽高比约束有效区域。
- 固定 60Hz 模拟，最多追赶 5 步。结束/重开不积累事件监听、定时器或 audio 节点；不在菜单后台运行模拟。

## 存档、声音与设置

- localStorage 数据含 schemaVersion、设置、角色解锁、最高成绩、累计统计；校验未知/缺损值和写入失败，提示但仍能玩；不保存进行中的局。
- 设置：普通技能自动释放、音乐音量、音效音量、画质（默认/低）、减少动态效果/关闭震屏。存档重载生效。
- WebAudio 原创合成短音效和简单背景音乐即可，不依赖外链资源。必须在用户交互后启用，暂停/后台停止音乐；独立音量。
- 开始按钮需等待必要资源和场景就绪，错误有中文提示和重试操作。
