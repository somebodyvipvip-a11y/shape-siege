# Shape Siege · 当前交接文档

更新日期：2026-10-07。唯一版本来源 VERSION，本地 0.15.1；线上上一已验证版本为 0.15.0。本轮修复用户反馈的手机三选一滚动与战场超大黑边。

## 根因与修改

- 三选一：竖屏固定卡高、装饰间距与完整属性条叠加。修复前 360×640 的弹窗 clientHeight=607，scrollHeight=816，第三张卡与重抽不在同屏；正常 DOM 断言可稳定复现。
- 黑边：viewportFor 将比例限制为 0.65～1.85，scene 居中缩小相机视口。390×844 仅绘制 390×600，上下合计 244px 留边；画布与页面都为 390×844、按钮容器仅 76px，证据排除按钮撑高。
- src/render/viewport.ts、scene.ts：实际比例与全尺寸相机视口，保留等面积 700000 世界单位，不拉伸图形。旋转保留世界与输入清理机制。
- src/ui/styles.css：手机三选一压缩装饰、属性条排成紧凑网格、卡片自然高度；完整名称/说明/数值/稀有标记保留，重抽最小 44px。不隐藏溢出；放大字体或超小窗口仍保留可滚动兜底。升级、事件奖励、通关礼包共用同一布局。横屏覆盖至 1050px，修复 932×430 旧断点遗漏；桌面正常窗口不变。
- tests/browser-rules.test.ts：六种手机比例的满屏面积回归。修复前 6 项失败，修复后通过；横竖屏等面积断言保留。
- README 同步满屏视野说明，CHANGELOG 记录 0.15.1。
