# Shape Siege · 当前交接文档

更新日期：2026-10-07。唯一版本来源 VERSION，本地 0.15.2；当前线上已验证版本 0.15.1。本轮修复电脑大窗口主角过大、可见环境过少的问题，等待提交与发布。

## 根因与修改

- 已确认根因：所有窗口固定 700000 世界单位视野面积，电脑窗口越大，相机越放大；1920×1080 下直径 32 的主角显示约 55px，2560×1440 约 73px。四组桌面回归断言修改前失败。
- src/render/viewport.ts：视野面积取 700000 与 CSS 窗口面积中的较大值。小窗口沿用手机视野，大窗口扩展可见环境，限制图形额外放大；实际比例与全屏相机视口保留。
- src/render/scene.ts：视野使用 CSS 尺寸，画布与相机视口使用实际像素；高像素比与低画质切换仅影响画布精度。角色半径、碰撞尺寸与技能参数未改。视野扩大会沿用现有可见范围外刷怪逻辑，刷怪距离随视野变化。
- tests/browser-rules.test.ts：新增四组桌面尺寸断言；原有六组手机满屏与旋转面积断言保留。README 与 CHANGELOG 同步新规则。

## 本轮验证

- 已验证：npm test 全部 144 项通过；npm run build 的类型检查与生产构建通过。既有 Phaser 大文件提示保留。
- 已验证：真实 Phaser 诊断页在 1366×768、1920×1080、2560×1440 下可见世界分别等于 CSS 窗口，主角本体均约 32px。390×844 与 932×430 仍为 700000 视野面积，画布/页面全屏，无页面滚动。等待 ResizeObserver 和相机完成更新后读取 DOM 诊断输出，避免把过渡帧误判为结果。
- 已验证：诊断页模拟 1.5 倍像素比，1920×1080 普通画质画布 2880×1620、低画质 1920×1080，两者世界视野均为 1920×1080；这是模拟证据，未代表真实高 DPI 设备验收。
- 已验证：正式 0.15.2 生产预览启动星环对局，桌面战场铺满，主角和地形显示比例正常，普通技能可触发；未捕获 Console error。截图 .superpowers/screenshots/desktop-v0.15.2-production.png。
- .superpowers/desktop-view.html 与截图是本地忽略产物，诊断页不代表正式对局。正式预览与诊断证据分别记录。
- 尚未验证：真实高 DPI 电脑、iOS Safari / Android Chrome 真机安全区与多点触控、后期性能及扩大视野后的长局节奏。
